 **Hotel Booking Cancellation Analysis**

## 🏨 Hotel Booking Cancellation Analysis Dashboard

## 📌 Project Overview

This project analyzes hotel booking data to understand booking patterns, cancellations, guest types, hotel types, room status, and monthly trends.

An interactive **Microsoft Excel Dashboard** was created using PivotTables, PivotCharts, slicers, and KPI cards.

## 📊 Dashboard Highlights

- **Total Bookings:** 119,390
- **Total Cancelled Bookings:** 44,224
- **Cancellation Rate:** 37.04%
- **City Hotel Bookings:** 79,330
- **Resort Hotel Bookings:** 40,060
- **City Hotel Cancellations:** 33,102
- **Resort Hotel Cancellations:** 11,122

## 📅 Monthly Analysis

The dashboard provides a month-wise comparison of total guests/bookings and cancelled bookings from **January to December**.

A **year slicer** is included to filter the dashboard by:

- 2015
- 2016
- 2017

## 🗂️ Dataset

The project uses the **Hotel Booking Dataset** stored in `hotel_booking.csv`.

The dataset contains **119,390 hotel booking records** and includes information such as:

- Hotel type
- Booking cancellation status
- Arrival date
- Guest information
- Room type
- Meal type
- Market segment
- Deposit type
- Customer type
- Booking changes
- Special requests
- Reservation status
- Average Daily Rate (ADR)
